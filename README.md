# SCSC Design docs

The published documentation of `@scscourt/design`: https://scscourt.github.io/scsc-design-docs/

Everything on this branch is generated from SCSCourt/scsc-design, a private repository, and served by GitHub
Pages. Each merge to its main branch rebuilds `/next/`, and each release adds its own
`/v<version>/` folder and refreshes `/latest/`. Every deploy replaces this branch with a single
new commit, so don't edit it: the next deploy discards the change.
